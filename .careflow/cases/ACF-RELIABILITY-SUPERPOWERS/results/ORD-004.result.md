## Summary

Added deterministic learning capture and promotion workflow. This turns the user's requirement for trouble/learning artifacts into commands that later Claude/Codex sessions can use to create canonical learnings and promote them into docs with source traceability.

## Changes

- Added `new_learning` and `promote_learning` lifecycle helpers.
- Added CLI commands:
  - `agent-careflow learning new --case <case_id> --title "..." [--source-incident <path>]`
  - `agent-careflow learning promote --case <case_id> --learning <LRN-...md> --target docs/... [--force]`
- `learning new` writes structured `.careflow/cases/<case_id>/learnings/LRN-*.md` artifacts with source incident, status, observation, implication, and follow-up sections.
- `learning promote` writes reader-facing docs with `source_learning` and refuses to overwrite existing docs unless `--force` is supplied.
- Promotion now updates source learning metadata before embedding the source snapshot, so promoted docs show `status: promoted` and `promoted_to: ...`.
- Case creation now creates a `learnings/` directory.
- Added lifecycle tests for learning creation, incident linkage, promotion, overwrite refusal, and force promotion.
- Updated README and design docs with learning capture/promotion guidance.
- Created and promoted a real learning:
  - `.careflow/cases/ACF-RELIABILITY-SUPERPOWERS/learnings/LRN-001-agent-workspace-learning-promotion.md`
  - `docs/learnings/agent-workspace-learning-promotion.md`
- Regenerated `.careflow/INDEX.md` and `.agent/` so the new learning is visible to later sessions.
