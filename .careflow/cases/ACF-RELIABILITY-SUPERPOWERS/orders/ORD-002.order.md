## Situation

ORD-001 created the runtime enforcement and handoff substrate, but the original objective also asks for plans and intermediate artifacts to live somewhere easy to see. Today a later Claude/Codex session must know or discover `.careflow/state.json` and then inspect individual files manually.

## Background

The user's business workflow moves across Claude, Codex, and subagents. A durable visible entrypoint reduces missed activation and mid-session forgetting because each session can start from one document that names the current plan, current order, expected result, evidence, incidents, and learnings.

## Assessment

Implement a small, testable dashboard/index layer rather than another prose rule. It should be generated from current artifacts and live under `.careflow/`, so it is portable across multi-repo roots and worktree layouts without copying tool-specific `.codex` or `.claude` config into target repositories.

## Recommendation

Add an `agent-careflow dashboard` command that renders current workflow state and can write `.careflow/INDEX.md`. Update docs and tests, then record fresh evidence in the expected result path.
