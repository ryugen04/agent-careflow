## Situation

The objective audit currently always evaluates the business dual-review policy. This correctly fails on this machine because the Claude review artifact is a placeholder, but it does not represent the user's private Codex-only requirement.

## Background

The user explicitly has two operating modes: business machines use Claude for research/planning and Codex for implementation, with both tools reviewing; private machines have no Claude subscription and must support Codex-only workflows.

## Assessment

A single global objective-audit review policy is too blunt. The audit needs profile selection: business remains strict, private validates Codex-only review and should not fail solely because Claude is unavailable.

## Recommendation

Add `--profile business|private` to objective-audit, default to business, and make review checks profile-aware. Preserve the existing business failure until a real Claude review is provided.
