## Situation

The original operating model explicitly uses Codex and Claude for review in business workflows. Current careflow has review validation, but not deterministic review creation or a required-review gate for Codex and Claude.

## Background

Business/C3 work should be able to require dual review artifacts. Private/Codex-only use should be able to require only Codex review, because Claude may not be available.

## Assessment

Review must be an artifact, not chat opinion. A CLI-based review workflow can create structured review files and validate that required tools have passing artifacts before close or handoff.

## Recommendation

Add `review new` and `review require`, update docs/tests, create real Codex and Claude review artifacts for this case, regenerate indexes, and record evidence in the expected result.
