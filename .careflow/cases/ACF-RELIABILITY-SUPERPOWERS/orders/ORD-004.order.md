## Situation

The current system can index manually written learnings, but the original requirement asks that troubles and learnings be output so another session can improve the workflow or create docs. Manual files are not enough evidence for a durable workflow.

## Background

Incidents already have a deterministic creation command. Learnings should have the same treatment and should support promotion into docs while keeping `.careflow` as the canonical source.

## Assessment

A `learning new` command makes capture repeatable. A `learning promote` command gives the next Claude/Codex session a safe path to turn lessons into documentation or improvements with source traceability.

## Recommendation

Add lifecycle helpers and CLI commands for learning creation and promotion, document them, run tests, regenerate indexes, and record evidence in the expected result.
