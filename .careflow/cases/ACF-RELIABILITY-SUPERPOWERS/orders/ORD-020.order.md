## Situation

ORD-019 attempted the remaining Claude review gate. The first run failed before authentication because the local Claude default selected `claude-opus-4-6` with deprecated `thinking.type=enabled`; retrying with `--model sonnet` reached the true remaining blocker: `401 Invalid authentication credentials`.

## Background

A business operator should not have to manually discover this fallback. The careflow review command should avoid known CLI default drift while keeping strict review validation intact.

## Assessment

Auto retrying only this known deprecated config failure with a safe fallback model improves reliability and does not weaken the final review gate. The real blocker remains external Claude authentication.

## Recommendation

Add a narrow fallback path, tests for fallback and explicit-model behavior, and evidence that current local execution now reaches the auth boundary directly.
