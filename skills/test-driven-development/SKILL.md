# Careflow Test-Driven Development

Use tests as evidence for the ORDER.

## Required Flow

1. Write or identify a failing test/evidence case for the requested behavior.
2. Run it and record the failure when practical.
3. Implement the smallest change inside ORDER scope.
4. Run the narrow test until it passes.
5. Run broader verification required by the PLAN.
6. Record red/green evidence in the RESULT or EVIDENCE directory.
