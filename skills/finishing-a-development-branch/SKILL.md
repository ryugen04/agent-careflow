# Finishing a Careflow Development Branch

Close only after evidence is current.

## Required Flow

1. Run PLAN-required verification.
2. Confirm every active ORDER is complete.
3. Confirm reviews are resolved for the risk class.
4. Validate close/discharge.
5. Present merge/PR/keep/discard options when user action is needed.
6. Preserve worktree cleanup as a separate explicit action.
