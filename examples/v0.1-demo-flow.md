# v0.1 Demo Flow

This demo shows the intended shape of agent-careflow. It is written as a handoff scenario, not as a feature catalog.

## 1. Bootstrap a target repository

```bash
agent-careflow bootstrap --target ../target-repo --profile private --careflow-repo "$PWD"
```

The target repo receives only `.careflow/careflow.yaml` and `.careflow/state.json`. Static policy and tool hook config remain in the central `agent-careflow` repo and are exposed through the user's global environment, such as dotfiles-managed links.

## 2. Create a case

```bash
cd ../target-repo
agent-careflow case new --title "Fix auth callback bug" --risk C2
```

This creates a case record under `.careflow/cases/<case_id>/`.

## 3. Write or validate the plan

```bash
agent-careflow hash plan --case <case_id> --write-lock
agent-careflow plan validate --case <case_id> --require-lock
```

The lock binds future orders to the exact plan content.

## 4. Issue a bounded order

```bash
agent-careflow order issue --case <case_id> --order ORD-001 --role implementer
agent-careflow order validate --case <case_id> --order ORD-001
```

The order must contain `plan_path`, `plan_hash`, and `expected_result_path`.

## 5. Render a subagent prompt

```bash
agent-careflow order prompt --case <case_id> --order ORD-001 --tool codex
```

The rendered prompt is what gets handed to Codex, Claude, or Cursor. The subagent receives a plan path, an order path, and an expected result path.

## 6. Agent works, result is recorded

The agent writes its result to the expected result path. The controller validates it:

```bash
agent-careflow result validate --case <case_id> --result ORD-001.result.md
```

## 7. Verify and review

Evidence files are added under `.careflow/cases/<case_id>/evidence/`.

```bash
agent-careflow phase advance --case <case_id> --to review
```

If evidence is missing or an incident is open, phase advancement fails.

## 8. Close the case

```bash
agent-careflow close validate --case <case_id>
```

`close validate` is the engineering alias for the careflow `DISCHARGE.md` artifact.
